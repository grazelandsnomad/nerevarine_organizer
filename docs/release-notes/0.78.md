# 0.78 release notes

_In development._ Changes land here as they're committed; this file becomes the
GitHub release body when `v0.78` is tagged (release.yml reads it by version).

## New features

- **Collapse All and Expand All.** Fold or unfold every section at once,
  from the Mods menu or by right-clicking any separator - until now this was
  one section at a time. A filter in the box is cleared first, since
  collapsing and filtering both hide rows and mixing them put rows back that
  the filter had taken away.

## Bug fixes

- **An app folder moved without its lists now says so.** The plain build keeps
  its mod lists next to the binary while its settings live under `~/.config`,
  so moving or re-extracting that folder without carrying `modlist_*.txt`
  along left the app knowing the game and the mods directory, with an empty
  list and no explanation - the first-run wizard does not fire, because the
  setting it reads survived the move. A banner now names the situation and
  offers the import, which can repoint a list whose mod paths have moved too.
  Reported on NexusMods.
- **Checking for updates asks Nexus once per game, not once per mod.** A
  check cost one request per installed mod - 409 of them on a large list,
  which is how it was possible to be refused outright by NexusMods for
  clicking the button a few times. Nexus will say in a single request which
  of a game's mods changed at all in the last month, so the check now asks
  that first and only looks up the few that actually moved. On a quiet week
  that is one request instead of hundreds, and the result is the same. If
  that reply does not arrive or cannot be read, every mod is asked about
  exactly as before.
- **The remaining-allowance features were doing nothing, and now work.** The
  app reads what NexusMods says it has left, to warn you when it runs low,
  stop before spending the last of it, and say when a refusal will lift. It
  was reading those figures from headers it looked up with the wrong
  capitalisation, so it never found any of them, and all three quietly did
  nothing in 0.77. It also could not read the times NexusMods sends, so a
  refusal could never say when to try again. Both are fixed against a real
  reply rather than the documentation.
