## Bug fixes

- **Updating a mod no longer asks whether to replace it.** On a free Nexus
  account an update is fetched by hand: the manager opens the mod page and
  you click "Mod Manager Download". Since 0.72 the mod stays installed while
  you do, so the download that came back met an installed copy and asked
  Merge / Install separately / Replace - though an update can only mean
  Replace. The download you were sent to fetch now replaces the mod without
  asking; any other file from the same page still asks.
- **Big zip archives no longer fail as "corrupt" and get thrown away.**
  Updating Sim Settlements 2 - Chapter 3 (a 5.6 GB zip) downloaded the whole
  file, said it was corrupt, deleted it and left the mod on its old version -
  every time. The download was fine: `unzip`, the only tool the manager used
  for zips, misreads some archives over 4 GB. A zip that `unzip` can't read
  is now unpacked with 7z, as RAR archives already fall back from unrar, and
  only a zip neither can open counts as broken.
- **The Dark mode button showed an empty box in the AppImage.** Its label
  started with the crescent-moon emoji, which only a colour emoji font has.
  The AppImage runs Qt 6.4, which looks for a missing character in at most
  255 fallback fonts and on a machine with many fonts never reaches the
  emoji font; the plain binary on a newer system Qt picks the emoji font
  directly. The label now uses a plain moon symbol (☽) that the common text
  fonts carry, like the ☀ of the Light mode label.
