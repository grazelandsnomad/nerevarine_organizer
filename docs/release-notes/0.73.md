## Bug fixes

- **Updating a mod no longer asks whether to replace it.** On a free Nexus
  account an update is fetched by hand: the manager opens the mod page and
  you click "Mod Manager Download". Since 0.72 the mod stays installed while
  you do, so the download that came back met an installed copy and asked
  Merge / Install separately / Replace - though an update can only mean
  Replace. The download you were sent to fetch now replaces the mod without
  asking; any other file from the same page still asks.
