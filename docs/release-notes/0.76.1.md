# 0.76.1 release notes

Released 2026-11-20. One fix, on the day 0.76 went out. Switching game and
switching back said your mod list had changed and offered to deploy again,
when nothing had changed: the plugin load order was one list for the whole
window rather than one per game, so coming back to a game judged its
deployment against the plugins of the one you had just left. It is held per
game now. The same flaw could write one modlist profile's load order into
another profile's file when switching profiles inside a game, so that goes
with it. Nothing else in 0.76 changes.

## Bug fixes

- **Switching game and back no longer claims your mod list changed.** The
  plugin load order was one list for the whole window, read from disk only at
  startup, so leaving a game filled it with the next game's plugins and coming
  back judged the first game's deployment against them. The deploy hint said
  the list had changed when nothing had, and it would not clear by itself. The
  order is now held per load-order file, the same file it has always been saved
  to, so the active game's order is whatever its own file holds. The same flaw
  could write one modlist profile's order into another's file when switching
  profiles inside a game; that goes with it.

## Migration notes

- Nothing to do. If a game is showing "your mod list has changed since it was
  last deployed" and you know it has not, the banner goes once this version
  has read that game's own load order, which it does the first time you look
  at the game.
- The plain binary keeps its mod lists and settings next to itself. Unpack
  0.76.1 over the old folder, or copy `modlist_*.txt`, `loadorder_*.txt` and
  `nerevarine_prefs.ini` across, to keep your list. The AppImage keeps its
  state under `~/.local/share/nerevarine` and needs nothing.
