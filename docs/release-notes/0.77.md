## Bug fixes

- **Switching game or modlist profile is much faster.** The app's own timings
  put one switch on a 438-row list at 620 ms, and a first switch after
  starting up at 10, 22 and even 70 seconds, all of it freezing the window.
  Most of that was work whose result was thrown away: the dependency scan
  rewrote three values per row that had not changed, and each one cost two
  full passes over every row; the save on the way out rewrote the config of
  the game being left and re-decorated rows the switch was about to destroy;
  the plugin order was re-sorted, which re-read every plugin file, only to
  find it had not moved; and the config sync re-read every enabled plugin's
  header instead of using the copies it already had. All four are fixed.
