## Bug fixes

- **The folder scan is remembered between runs.** Working out which plugins
  each installed mod ships meant opening every mod folder, and on a 409-mod
  library that measured 16.8 seconds the first time a game was left in a
  session, with another 5.7 reading those plugins' masters. Both are now
  written down and read back, and an entry is trusted only while every
  directory it was built from still carries the time it had - which is a stat
  each, measured at 0.002 ms against 6.8 ms to reopen one directory. So the
  work happens once, when something actually changes, instead of once per run.
- **Leaving a game no longer re-derives a load order it already has.** This
  was the last and worst of it: 38 seconds of a profile switch, measured, spent
  asking the filesystem which plugins each of 409 installed mods ships - to
  produce the order already sitting in the file. The order file now records
  what it was built from, so when nothing has changed there is nothing to do
  and no folder is read. The first switch after upgrading still pays once,
  because existing files do not carry that record yet; after that it is free.
- **Opening a game's list for the first time is faster too.** Deciding whether
  each mod is installed cost two filesystem round trips per row, and on a
  library of 405 folders that measured 4.1 seconds the first time and 1 ms
  every time after, because the answer sits in the kernel's cache once it has
  been read. It is one round trip now, which is the same answer in half the
  work, and the folders of the games you are not looking at are read in the
  background so that the first switch to them finds them already warm.
- **Switching game or modlist profile is much faster.** The app's own timings
  put one switch on a 438-row list at 620 ms, and a first switch after
  starting up at 10, 22 and even 70 seconds, all of it freezing the window.
  Most of that was work whose result was thrown away: the dependency scan
  rewrote three values per row that had not changed, and each one cost two
  full passes over every row; the save on the way out rewrote the config of
  the game being left and re-decorated rows the switch was about to destroy;
  the plugin order was re-sorted, which re-read every plugin file, only to
  find it had not moved; and the config sync re-read every enabled plugin's
  header instead of using the copies it already had. All four are fixed.
